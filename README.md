# Fi-Weath — Weather App

A simple and responsive weather application built using HTML, Bootstrap CSS, and JavaScript.
The app fetches real-time weather data from a public API for a given city and displays the current temperature in Celsius.

### https://beslinebby.github.io/Fi-Weath/

### 🌤️ Overview

Fi-Weath is a front-end weather app that allows users to search weather information using a city name. On the initial load, the application automatically displays weather details for a default city.

### ✨ Features

- search weather by city name

- Displays temperature in Celsius

- Shows weather icons

- Shows weather condition details

- Loads a default city’s weather on first render

- Lightweight and fast (no backend required)

### 🧰 Technologies Used

- HTML5 — page structure

- Bootstrap CSS — responsive layout and styling

- JavaScript (ES6+) — logic, API calls, DOM updates

- OpenWeatherMap API — weather data source
